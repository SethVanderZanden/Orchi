# Establish Visual Hierarchy

## Define the intended order

1. List what users should notice first, understand second, and act on next.
2. Rank content and actions by task importance, not organizational preference.
3. Identify the primary action, supporting actions, metadata, and low-priority utilities.
4. Compare that order with the interface's current visual salience.

## Build the hierarchy

- Use position and grouping before adding decoration.
- Reserve the strongest combination of size, weight, contrast, and color for the highest priority.
- Create clearly distinguishable heading, body, label, and metadata roles.
- Give one action primary emphasis within a decision context; make alternatives visibly subordinate without making them undiscoverable.
- Repeat hierarchy rules consistently across related screens.
- Preserve reading order between the visual layout and the underlying document or focus order.

## Check competing signals

- Remove emphasis from elements that are loud but unimportant.
- Avoid making every card, heading, badge, and button visually dominant.
- Ensure large imagery or decorative color does not overpower the task.
- Check whether disabled, selected, focused, warning, and destructive states remain distinguishable.
- Test the design in grayscale and at a glance to expose reliance on color or weak grouping.

## Make responsive decisions

- Preserve priority when columns stack or navigation condenses.
- Move important content earlier rather than relying only on larger styling.
- Keep the primary action visible at the appropriate task moment; do not make it permanently sticky without need.
- Reassess hierarchy when labels wrap, text grows, or data is missing.

## Avoid these failures

- Do not use size as the only hierarchy tool.
- Do not equate brand prominence with task priority.
- Do not create visual order that conflicts with keyboard or screen-reader order.
- Do not use low contrast to make secondary content effectively unreadable.
- Do not introduce multiple primary actions into one decision.

## Produce the result

Provide:

1. The intended attention sequence.
2. The mismatches between importance and visual salience.
3. Specific changes to position, scale, weight, contrast, color, or action treatment.
4. Responsive and accessibility checks.
5. A short before-and-after hierarchy specification.
